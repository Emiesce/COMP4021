QuickDraw Slayers

Run

  1. npm install
  2. node game_server.js
  3. Open http://localhost:8000 in two browsers (or one normal + one private window).

Seed accounts: tony / t and may / m. Or register new ones.

Files

  • game_server.js - Express, sessions, register/signin/validate/signout, Socket.IO (shares the login session)
  • server/lobby.js - rooms, pairing, ready, countdown, rematch (all per room)
  • server/game.js - game logic for one room (empty for now)
  • public/ - index.html, style.css, scripts/ (lobby.js, game.js, plus the lab modules)

Socket.IO events

The full list is in the comments at the top of server/lobby.js.
