Run

  1. npm install
  2. node game_server.js
  3. Open http://localhost:8000 in two browsers (or one normal + one private window).

Register an account, read the How to Play guide, then sign in.

Files

  • game_server.js - Express, sessions, register / sign in / validate / guide-complete / sign out, sign-in limits, Socket.IO (shares the login session)
  • server/store.js - data files (creates them if missing, atomic writes)
  • server/ratelimit.js - "too many failed attempts" limiter
  • server/lobby.js - rooms, pairing, ready, countdown, rejoin after a refresh (event list at the top of the file)
  • server/game.js - per-room lifecycle boundary for the multiplayer game
  • public/ - index.html, style.css, scripts/ (game_room.js accounts, howto.js guide, lobby.js lobby, game.js playable canvas prototype)
  • test/platform.test.js - automated checks for accounts, sessions, rooms and rejoin

Accounts

Accounts are stored in data/users.json (passwords hashed with argon2). The file is created automatically if it is missing.

Tests

npm test starts a separate server on port 8123 with a temporary data folder and prints PASS / FAIL lines.

Gameplay prototype

Choose Play Solo in the lobby to open a one-player canvas battle immediately. Click a card or use 1-4; the complete three-floor loop is playable without waiting for another account or connecting combat state over Socket.IO.
